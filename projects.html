DNS library

Parsing and generating DNS messages from scratch.

C++ library that parses and emits DNS messages, including the on-wire compression scheme. Ships with example resolvers that demonstrate end-to-end queries over UDP and TCP.

Interactive walk-through of a classic string algorithm.

TypeScript and D3 tool that animates each step of building a suffix automaton — useful both as a teaching aid and as a sanity check while implementing the algorithm.
